# HUDZoomBlur

HUDZoomBlur is a lightweight, client-side Minecraft mod designed for Minecraft 1.21.11, built using the Fabric modding API. This mod enhances your gameplay experience by providing a customizable Heads-Up Display (HUD) with keystrokes, Click-Per-Second (CPS) counter, and mouse movement indicators. It also includes a zoom feature and a motion blur shader for a more immersive visual experience. The mod is fully client-side, ensuring minimal performance impact and no server-side installation required.

## Install

1. Ensure you have the Fabric mod loader installed for Minecraft 1.21.11.
2. Download the latest release of HUDZoomBlur from the [GitHub repository](https://github.com/enderdevelopment/enderdev-hud).
3. Place the downloaded JAR file into your Minecraft mods folder.
4. Launch Minecraft with the Fabric profile.

## Use

1. Launch Minecraft and load a world.
2. Access the mod settings by pressing the designated hotkey (default: 'P') or through the Mod Menu.
3. Customize the HUD position, scale, and toggle features on/off as desired.
4. Use the zoom feature by pressing and holding the zoom hotkey (default: 'C').
5. Toggle the motion blur shader on/off and adjust its intensity in the settings menu.
