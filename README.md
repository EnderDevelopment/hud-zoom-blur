# EnderDev HUD Mod

EnderDev HUD Mod is a lightweight, client-side utility Minecraft mod designed for Fabric API targeting Minecraft 1.21.11. It combines an overlay HUD with keystrokes, CPS, and mouse movement indicators, performance/visual shaders like motion blur and zoom, and customizable RGB styling. The mod is entirely client-side, ensuring minimal overhead and no server-side installation requirements.

## Install

1. **Prerequisites**:
   - Install Java Development Kit (JDK) 17 or later.
   - Install Minecraft 1.21.11.
   - Install Fabric API for Minecraft 1.21.11.

2. **Clone the Repository**:
   ```sh
   git clone https://github.com/enderdevelopment/enderdev-hud.git
   cd enderdev-hud
   ```

3. **Build the Mod**:
   ```sh
   ./gradlew build
   ```

4. **Install the Mod**:
   - Locate the built JAR file in the `build/libs` directory.
   - Copy the JAR file to the `mods` folder in your Minecraft instance directory.

## Use

1. **Launch Minecraft**:
   - Ensure the Fabric API and EnderDev HUD Mod are loaded.

2. **Access the HUD**:
   - The HUD will automatically display keystrokes, CPS, and mouse movement indicators.

3. **Zoom Feature**:
   - Press and hold the 'C' key to zoom in. The zoom level can be adjusted in the settings.

4. **Motion Blur**:
   - Enable motion blur in the settings menu and adjust the intensity as needed.

5. **Customization**:
   - Access the settings menu via the Mod Menu or a designated hotkey to customize the HUD position, scale, and toggle features on/off.
   - Enable the RGB color-shifting mode for dynamic color changes.
